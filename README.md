# Credit Card Analysis Dashboard

## Project Overview

This project is an interactive Credit Card Analysis dashboard developed using Microsoft Power BI.

The dashboard analyzes credit card transactions, customer demographics, spending patterns and credit risk indicators to provide meaningful business insights.

## Objectives

- Analyze overall credit card transaction performance
- Understand customer demographics and income groups
- Analyze transaction amount and transaction volume
- Compare different card categories
- Analyze credit utilization and delinquent accounts
- Identify patterns in customer and credit card data

## Dashboard Pages

### Page 1 – Credit Card Overview

This page provides an overview of credit card transaction performance.

Key analysis includes:
- Total Transaction Amount
- Total Transaction Volume
- Maximum Credit Limit
- Credit Limit by Expense Type
- Credit Limit by Card Category
- State-wise Transaction Analysis

### Page 2 – Customer Analysis

This page focuses on customer demographics and characteristics.

Key analysis includes:
- Customer Count
- Income Groups
- Gender
- Marital Status
- Education
- Customer Satisfaction
- Customer Segmentation

### Page 3 – Credit Risk Analysis

This page focuses on credit risk and utilization-related analysis.

Key analysis includes:
- Total Delinquent Accounts
- Total Revolving Balance
- Average Utilization Ratio
- Total Interest Earned
- Transaction Amount by State
- Credit Risk by Card Category
- Interest Earned by Customer Job

## Tools & Technologies

## Key Features

- Interactive dashboards
- KPI cards
